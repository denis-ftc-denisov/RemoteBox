ALWAYS BEFORE PACKAGING
-----------------------

1. REMOVE ANY OBVIOUS JUNK OR DUMMY CODE
2. REMOVE USE DUMPER;
3. REMOVE JUNK FILES FROM FOLDER (BASICALLY CREATE A NEW ONE AND COPY WHAT IS NEEDED)
4. Update versioning information, including supported versions of VirtualBox
5. Update to the latest vboxService.pm
6. Make sure the recommended version error box is correct
